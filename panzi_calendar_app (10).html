Importer des publications
Importez votre rapport Hootsuite en PDF. Idéalement un rapport avec un tableau « Posts table » par plateforme (Facebook - US, Facebook - DRC, Instagram, LinkedIn, TikTok, Twitter/X - US, Twitter/X - DRC) : chaque publication est alors attribuée à la bonne plateforme.

Astuce : le PDF ne montre qu'une partie de chaque tableau. Exportez des périodes courtes (1–2 semaines) pour que tout entre, et importez chaque PDF l'un après l'autre — les données s'accumulent sans s'écraser. Après import, vérifiez le décompte par plateforme affiché ci-dessous.

Deux systèmes distincts — ne pas confondre

1. CODES SOURCE — pour la plateforme de dons (GoFundMe, Classy). Deux champs séparés :
• Code source 1 = le média : email_update, email_newsletter, popup_donate, meta-instagram
• Code source 2 = la campagne + langue : may_2022_eng, eoy_2026_rhoda_eng, jointhemovement_eng

2. UTM — pour Google Analytics. GA n'affiche en pratique qu'une seule valeur utile, donc utm_campaign doit tout contenir :
média + période + sujet + langue → newsletter_may_2026_SVSunit_eng
